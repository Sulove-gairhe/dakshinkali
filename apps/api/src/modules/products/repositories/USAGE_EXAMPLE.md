# ProductRepository Usage Example

This document demonstrates how to use the ProductRepositoryImpl for database operations.

## Setup

```typescript
import { getSupabaseClient } from '@packages/database/supabase.config';
import { ProductRepositoryImpl } from './repositories';
import { ProductEntity, ProductStatus } from './entities/product.entity';

// Initialize repository with Supabase client
const supabase = getSupabaseClient();
const productRepository = new ProductRepositoryImpl(supabase);
```

## Insert a Product

```typescript
const newProduct: ProductEntity = {
  id: '', // Will be generated by database
  name: 'iPhone 15 Pro',
  description: 'Latest iPhone with A17 Pro chip',
  price: 999.99,
  category: 'Electronics',
  status: 'active' as ProductStatus,
  images: [
    {
      id: 'img-001',
      url: 'https://storage.example.com/products/iphone-15-pro.jpg',
      filename: 'iphone-15-pro.jpg',
      order: 0
    }
  ],
  createdAt: new Date(), // Will be set by database
  updatedAt: new Date(), // Will be set by database
  deletedAt: null
};

try {
  const insertedProduct = await productRepository.insert(newProduct);
  console.log('Product inserted:', insertedProduct);
  // insertedProduct will have:
  // - Generated UUID in id field
  // - Database-generated timestamps
  // - All fields properly typed (price as number, dates as Date objects)
} catch (error) {
  console.error('Failed to insert product:', error);
}
```

## Row-to-Entity Mapping

The repository automatically handles all type conversions:

### Database Row (from PostgreSQL)
```typescript
{
  id: '123e4567-e89b-12d3-a456-426614174000',
  name: 'iPhone 15 Pro',
  description: 'Latest iPhone with A17 Pro chip',
  price: '999.99',  // ← NUMERIC type comes as string
  category: 'Electronics',
  status: 'active',
  images: '[{"id":"img-001","url":"https://...","filename":"...","order":0}]',  // ← JSONB as string
  created_at: '2024-01-15T10:30:00.000Z',  // ← TIMESTAMPTZ as ISO string
  updated_at: '2024-01-15T10:30:00.000Z',
  deleted_at: null
}
```

### Mapped ProductEntity (domain model)
```typescript
{
  id: '123e4567-e89b-12d3-a456-426614174000',
  name: 'iPhone 15 Pro',
  description: 'Latest iPhone with A17 Pro chip',
  price: 999.99,  // ← Converted to number
  category: 'Electronics',
  status: 'active',
  images: [  // ← Parsed from JSONB
    {
      id: 'img-001',
      url: 'https://...',
      filename: '...',
      order: 0
    }
  ],
  createdAt: Date('2024-01-15T10:30:00.000Z'),  // ← Converted to Date object
  updatedAt: Date('2024-01-15T10:30:00.000Z'),
  deletedAt: null
}
```

## Type Conversions Handled

1. **JSONB → ProductImage[]**
   - Parses JSON string to array of objects
   - Handles both string and already-parsed formats
   - Returns empty array if parsing fails

2. **NUMERIC → number**
   - Converts string representation to JavaScript number
   - Handles both string and number formats from Supabase

3. **TIMESTAMPTZ → Date**
   - Converts ISO 8601 strings to Date objects
   - Handles null values for optional timestamps (deletedAt)

4. **snake_case → camelCase**
   - Maps database column names to entity property names
   - created_at → createdAt
   - updated_at → updatedAt
   - deleted_at → deletedAt

## Error Handling

The repository translates database errors to domain-friendly messages:

```typescript
// Unique constraint violation (duplicate name in category)
try {
  await productRepository.insert(duplicateProduct);
} catch (error) {
  // Error: "A product with name 'iPhone 15 Pro' already exists in category 'Electronics'."
}

// Generic database errors
try {
  await productRepository.insert(invalidProduct);
} catch (error) {
  // Error: "Failed to insert product: [database error message]"
}
```
